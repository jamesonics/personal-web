# James Liu — Personal Website

A static-first personal website for research, projects, writing, CV, and personal stories.

## Stack

- Astro 7
- Markdown content collections
- Vanilla CSS and JavaScript interactions
- Pagefind static search index
- GitHub Pages deployment

## Commands

```bash
npm install
npm run dev
npm run check
npm run build
npm run preview
```

## Content

- Personal/site data: `src/data/`
- Writing: `src/content/writing/`
- Pages: `src/pages/`
- Images and CV PDFs: `public/`
