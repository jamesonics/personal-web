# Personal Website

Source code for Liu Zihan / James Liu's personal website.

The active Astro application lives in [`website/`](website/). It is built and deployed to GitHub Pages by [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

Before making changes, read [`AGENTS.md`](AGENTS.md). UI work must also follow [`docs/UI_DESIGN_SYSTEM.md`](docs/UI_DESIGN_SYSTEM.md).

```bash
cd website
npm install
npm run dev
npm run build
```
