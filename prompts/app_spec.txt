## 项目概述

项目名称: Personal Web
项目类型: 个人网站
创建日期: 2025-02-15
框架版本: Long-Running Agent Harness v1.0

## 项目目标

创建一个现代化的个人网站，用于展示：
- 个人信息和简介
- 技术技能和专业能力
- 项目作品集
- 联系方式

### 前端

- [可选] Tailwind CSS / Bootstrap

### 工具

- [可选] Webpack / Vite 构建工具

## 功能需求

### 必需功能 (Must Have)
1. 响应式导航栏
2. 首页Hero区域
3. 项目展示区
4. 技能展示区
5. 联系方式区
6. 页脚组件

### 期望功能 (Nice to Have)
1. 深色/浅色主题切换
2. 页面滚动动画
3. 博客功能
4. 多语言支持

### 性能要求
- 首页加载时间 < 3秒
- Lighthouse 性能分数 > 90
- 移动端友好

### 技术约束
- 不使用jQuery
- 不使用过时的CSS特性
- 保持代码简洁，避免过度工程

### 时间约束
- 按功能优先级顺序开发
- 每个会话专注一个功能

### 质量约束
- 必须进行端到端测试
- 代码必须有意义的提交消息
- 保持代码可维护性
