四条工作主线

从工作内容、个人贡献、团队价值和证据状态四个层次展开。

01

团队 Harness 建设

工作内容

围绕真实任务执行、工具与环境适配、调试和可观测能力，参与团队 Agent Harness 的持续建设。

个人贡献

参与梳理真实任务执行所需的通用能力，并持续补齐工具、环境、调试与可观测链路。

团队价值

让 Agent 更稳定地完成真实任务，降低问题定位与迭代成本。

结果与证据

具体项目、能力覆盖范围与效果指标将在后续获得可公开证据后逐项补充。

02

评测 Runtime 链路改造

工作内容

推进评测 Runtime 链路改造和能力原子化，支持不同 Agent 以更统一的方式接入横向评测。

个人贡献

参与链路改造和能力边界拆分，使平台原子能力能够被不同 Agent 组合复用。

团队价值

减少重复适配，提高评测的一致性、可比性与扩展效率。

结果与证据

后续重点补充 Agent 接入周期、定制适配量、运行成功率和任务覆盖范围。

03

平台质量与问题治理

工作内容

参与平台 On-call 与缺陷治理，完善资源访问校验、异常处理和回归验证。

个人贡献

参与问题定位、修复方案落地和回归验证，将单点问题转化为更完整的质量防线。

团队价值

降低稳定性和权限边界风险，保护评测资产与结论可信度。

结果与证据

公开页面仅保留问题治理方法；具体安全发现、内部链路和业务数据不对外披露。

04

工程支持与自驱探索

工作内容

承接跨模块工程支持，并围绕 Agent、Agentic RL、后训练与模型评测持续学习和实践。

个人贡献

在完成即时支持的同时识别共性问题，并通过文档、工具或实验记录形成可复用沉淀。

团队价值

把即时问题沉淀为可复用的认知、文档和工具，降低后续重复成本。

结果与证据

后续将把适合公开的探索整理为 Blog、项目复盘和面试表达材料。

价值与结果的记录方式

不把功能完成直接等同于成果，而是持续补齐问题价值、关键行动、结果指标和因果证据。

以价值为取向、结果为导向，在 Agent 研发与评测链路中寻找影响团队效率、能力覆盖和结果可信度的关键瓶颈。

  1. 问题价值明确工作解决了谁的什么瓶颈，以及不处理会产生的成本或风险。
  2. 关键行动说明我改变了哪一段链路、能力边界或协作方式，以及其中的个人贡献。
  3. 结果与指标通过成功率、覆盖范围、接入周期、稳定性或风险变化判断工作是否落地。
  4. 因果证据使用链路测试、运行记录、使用反馈和改造前后对比约束结果归因。
