These skills are vendored as project-local Codex skills under `.agents/skills/`.
Repository instructions in `/AGENTS.md` and `/docs/UI_DESIGN_SYSTEM.md` remain authoritative for this personal website. In particular, use these skills to improve craft without introducing a separate palette, typography system, card system, navigation, heavy animation dependency, or visual identity.

## Included skills

- `emil-design-eng`: general UI polish and design-engineering guidance
- `animate`: implement a justified animation
- `review-animations`: strict review of an animation diff
- `improve-animations`: read-only motion audit and implementation plans
- `find-animation-opportunities`: read-only search for worthwhile motion
- `animation-vocabulary`: identify motion terminology
- `apple-design`: Apple-inspired interaction and fluid-motion principles
- `pick-ui-library`: curated UI library selection
- `prototype`: compare multiple UI variants
- `ask-sonner`: Sonner toast guidance
