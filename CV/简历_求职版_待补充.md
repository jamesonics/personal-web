### Paper Reading Automation 论文智能解析系统 | 独立开发者
*2025年 - 至今*

**项目简介**：基于 **Claude Code Skill** 构建的论文智能解析自动化工具，实现从 PDF 论文**扫描、去重、多模态解析、LLM 深度分析到自动同步飞书/Notion**的全流程自动化。专为科研工作者设计，解决论文管理和知识整理痛点。

**技术栈**：Python 3.11、PyMuPDF、pdfplumber、智谱 GLM-4.6V（多模态）、GLM-4-Plus、asyncio、SQLite、飞书开放平台 API、Notion API

**架构设计**：
```
┌─────────────────────────────────────────────────────────────┐
│                Claude Code Skill 入口（6步工作流）            │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐ │
│  │ MD5去重  │──▶│PDF解析   │──▶│LLM深度   │──▶│双平台    │ │
│  │ 文件扫描 │   │(多模态)  │   │分析      │   │同步上传  │ │
│  └──────────┘   └──────────┘   └──────────┘   └──────────┘ │
│                      │                              │        │
│               ┌──────┴──────┐              ┌───────┴───────┐│
│               ▼             ▼              ▼               ▼│
│        ┌───────────┐ ┌───────────┐  ┌──────────┐  ┌──────────┐
│        │GLM-4.6V   │ │pdfplumber │  │  Notion  │  │  飞书    │
│        │多模态解析 │ │降级方案  │  │   API    │  │ 多维表格 │
│        └───────────┘ └───────────┘  └──────────┘  └──────────┘
└─────────────────────────────────────────────────────────────┘
```

**个人贡献**：
- **Claude Code Skill 工作流设计**：定义 6 步自动化流程（环境初始化 → 扫描 → 解析 → 保存 → 上传 → 状态更新），支持自然语言触发完整流程
- **多模态 PDF 解析器开发**：使用 PyMuPDF 将 PDF 转图像，通过 GLM-4.6V 视觉模型逐页分析，保留图表和排版信息
- **异步并发优化**：使用 `asyncio` + `ThreadPoolExecutor`（20线程）实现并发 API 调用，Semaphore 限制并发数为 10
- **降级策略设计**：多模态解析失败（如 API 余额不足）时自动切换到 pdfplumber + GLM-4-Plus 方案，保证服务可用性
- **双平台集成**：开发统一上传处理器 `UnifiedUploader`，支持 Notion 数据库和飞书多维表格的自动同步

**技术亮点**：
- **MD5 智能去重**：分块读取计算哈希，自动识别已处理论文，SQLite 追踪处理状态
- **LLM 智能聚合**：多页解析结果通过 GLM-4-Plus 进行内容提炼，提取 3-5 个核心要点
- **领域定制 Prompt**：设计叶轮机械智能体启发提取 Prompt，分析论文对垂直领域的可迁移价值

**项目成果**：
- ✅ 完整的 6 步自动化论文处理流程
- ✅ 提取 10 个结构化字段（标题、作者、摘要、创新点、局限性、领域启发等）
- ✅ 支持 Notion 和飞书双平台同步
